## Featured Projects

### [Snowflake AI-Agent Governance & ETL Pipeline](https://github.com/pavanG945/snowflake-ai-governance-etl)
Connected an AI coding agent (Claude Code) to live Snowflake data via **MCP (Model Context Protocol)**, with SQL permissions enforced server-side rather than relying on the AI's judgment. Built a Medallion (Bronze/Silver/Gold) pipeline that cleaned 200,000 raw records (excluding 57,169 invalid rows) and a conventional ETL pipeline (Internal Staging, Streams, Tasks) with verified incremental processing.
`Snowflake` `MCP` `Claude Code` `SQL` `Data Governance`

### [WWI Capstone: Medallion Architecture Data Pipeline](https://github.com/pavanG945/WWI)
End-to-end Bronze → Silver → Gold data pipeline on **Databricks**, using the Wide World Importers dataset. Monthly S3 ingestion, PySpark-based cleaning with a dedicated data-quality logging framework, and a full star-schema warehouse (7 dimension tables, 6 fact tables) with a sales summary rollup.
`Databricks` `PySpark` `Delta Lake` `AWS S3` `Data Warehousing`
